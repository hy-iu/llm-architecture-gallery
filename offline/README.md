# Offline LLM Architecture Gallery

This directory is an offline export of the repository metadata and architecture images.

- `models.yml`: all model parameters and links from the source metadata, with `image` fields rewritten to local paths.
- `images/architectures/`: downloaded architecture diagrams, deduplicated by filename.
- `manifest.json`: model-to-image mapping and original image URLs.

The links in `models.yml` remain external references for articles, configs, licenses, technical reports, and benchmark pages. This bundle does not redistribute model weights or third-party documents.
